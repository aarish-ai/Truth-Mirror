# Security Policy

## Supported Versions

Please check the project documentation for the list of supported versions. Currently, we recommend using the latest version of the main branch.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in this project, please report it to us as described below.

**Please contact us at:** aarishmuhammad.pk@gmail.com

Please include the following details with your report:
* A description of the vulnerability.
* Steps to reproduce the issue.
* Any possible proof-of-concept (PoC).

We will try to respond to your report within a reasonable timeframe, providing an initial assessment of the vulnerability and a planned course of action.
